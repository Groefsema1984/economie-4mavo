# Economie 4 MAVO · oefenapp

Interactieve oefenapp voor economie 4 MAVO (methode Pincode, H1–H8) met eindexamentrainer (alle centrale examens 2018-2026), flitskaarten, proeftoetsen en kern/methode/verdieping per begrip.

- App: `index.html` (één bestand, wordt gebouwd uit `src/` met `python3 src/build.py`)
- Server: `server/Code.gs` (Google Apps Script + Google Sheet)
- Lagen per begrip: `src/lagen.txt` (k = kern, m = methode, v = verdieping)
- Uitleg voor de docent: [HANDLEIDING-DOCENT.md](HANDLEIDING-DOCENT.md)
